# 个人记忆库管家

帮助建立和维护供 Agent 长期使用的个人信息库。重点是根据个人目标、约束、偏好、近期状态和真实反馈改变帮助方式，并提出有价值的反问。

## 安装与分享

分享完整的 `personal-memory-vault` 文件夹或对应 ZIP，不要只复制 `SKILL.md`，也不要把个人信息库一起打包。

Codex 用户解压到自己的 `$CODEX_HOME/skills`；未设置 `CODEX_HOME` 时使用 `~/.codex/skills`。应得到 `personal-memory-vault/SKILL.md`，避免嵌套同名文件夹。新会话中确认技能可被选择，再使用下列指令。

其他支持 Agent Skills 的工具可按该工具的导入方式加载整个文件夹；本包未逐一验证其他工具。核心记忆流程使用 Markdown 和文件读写，不要求联网、向量库或特定连接器。可选的个性化选读需要检索和全文读取能力；定时运行还需要宿主调度工具。

## 开始使用

新建时，把路径换成自己的目录：

```text
使用 $personal-memory-vault，在【填写你自己的目录完整路径】建立个人信息库。
我希望它主要帮助我做学习安排和日常取舍。
已有信息先复用，缺少的关键条件逐个问我。
先建立最小可用版本，并说明以后如何读取、更新和验证效果。
```

评估已有库：

```text
使用 $personal-memory-vault，只读评估【填写你自己的目录完整路径】里的个人信息库。
重点检查它能否帮助 Agent 理解我的需求，区分已验证的问题与改进建议。
这次不要改文件。
```

授权持续维护时，应同时指定真实目录与范围，例如：

```text
使用 $personal-memory-vault，由你持续维护【填写你自己的目录完整路径】里的个人信息库。
允许在库内记录我明确表达的目标、偏好、约束，以及我提供的实际反馈，
并自动完成相关整理、查重、导航和历史替代。
无法解决的冲突和你推断出的长期模式先问我。
请记录维护约定；不要据此创建定时任务或读取其他聊天、账户。
```

安装技能不会自动授予读写权限，也不会自动监听聊天。个人内容始终保存在用户自己的库里，不能写回这份可分享技能。

## 可选：个性化选读

根据个人库的当前目标、状态、知识基础和阅读反馈，先比较至少三个候选，再阅读全文核查质量与契合度。每天最多一篇，每周最多三篇；没有合适内容就不推荐。支持文章和现成周刊，不默认生成一份原创日报。

来源可以是自己指定的网站、作者、RSS 和现成周刊，也可以按当前主题公开检索。优先使用已有联网或订阅能力；平台内容读不到时，可用已有的 Agent Reach 补缺，不要求安装它或部署 AIHOT。具体渠道按实际环境核对，返回文字不代表已经取得全文。来源配置、采集状态和推荐历史保存在使用者授权的私有位置。详见 [来源与采集](references/reading-sources.md)。

默认稳定来源为主、少量探索。先用五项入口筛查决定是否值得试读，再按正文识别质量与营销问题。来源最近实际审核的三篇不同完整内容可跨主题、跨轮累计；均合格后转稳定，并记录已查主题，不据此推断其他领域的专业能力。当前选读优先，每轮为分级额外读取总计最多三条，已有审核直接复用，推荐上限不限制阅读数量。有稳定来源时每轮最多引入一个新来源；没有稳定来源的首轮最多考察三个。具体状态、筛查和审核规则统一见 [来源与采集](references/reading-sources.md)，记录权限不变。

没有来源名单也可使用：Agent 根据当前需求，从人工精选入口找线索，从好文章反查作者和栏目，再沿引用或推荐少量扩展，必要时用公开搜索补缺。目录和作者推荐只是候选线索，仍须抽读正文，不自动订阅或登录。这个包提供发现与审核流程，不附带一份已替所有使用者验证的优质来源名单。

手动试选不需要先开订阅：

```text
使用 $personal-memory-vault，根据【个人库路径】里与当前需求有关的信息，
为我手动精选今天值得读的文章或现成周刊，最多一篇。
先粗筛再阅读全文，质量不够就不推荐。
用中文给简短导读、具体推荐理由、发布日期和原文链接。
这次只在当前对话呈现，不写库、不创建定时任务。
```

需要持续选读时再给出频率、时间、时区、交付位置和可保存历史的位置：

```text
使用 $personal-memory-vault，为【个人库路径】配置每日或每周选读。
已有个人信息先复用，只问实际运行还缺的条件。
按每日零至一篇、每周零至三篇筛选；没有合格内容就静默跳过。
说明交付方式和推荐历史的保存位置；在我明确请求的范围内设置，
宿主没有调度或发送能力时如实说明，不假装已启用。
```

外文默认提供中文标题和导读。需要时可以展开背景、术语和核心论证；用户提供原文或获授权、许可允许时，再提供全文译文。无法取得全文的内容不进入最终推荐。

跨日、跨周根据原文链接和周刊期次去重。只有在允许保存推荐记录的位置有可用历史时，才能核实跨期去重；无回复不当成不感兴趣，推荐内容不自动写成个人画像。

详细规则见 [个性化选读](references/reading-curation.md)。安装技能和普通建库均不会自动创建选读任务。

## 包含内容

`SKILL.md` 是 Agent 的工作入口；`references/` 包含建库模型、维护与反馈、可选选读、效果验收和设计依据；`agents/openai.yaml` 提供 Codex 界面元数据。

结构校验只能验证技能格式。个人化效果仍需用真实问题、新会话和用户反馈验证。
