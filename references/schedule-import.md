# 把课表 / 日历导进库

用户发来 `.ics`、教务系统导出或截图时用这条流程。目标是产出一页能回答「今天有什么课、这周哪天空」的课表，外加能推算空档的结构化数据。

## 先认来源，不要凭印象补

- `.ics`：可解析，能拿到重复规则、地点、教师。
- 截图 / Excel：先确认有没有周次和节次信息，再决定人工转写还是只做粗略表。
- 拿不到文件就留空，并在页内写清「需要什么」；不要凭记忆填课程名，那是最容易被用户当场纠正的一类错误。

## .ics 解析要点

1. **先展开重复规则，不要只读 DTSTART。** 一个学期常被拆成多条 VEVENT（国庆、调课、分段），只读首条会漏掉后半学期。逐条 `FREQ=WEEKLY` 按 `UNTIL` 展开，再合并。
2. **`UNTIL` 是 UTC。** `...T160000Z` 在 UTC+8 是次日 00:00；直接与本地 DTSTART 比较会多算或少算一周。
3. **时间是唯一可靠字段。** 导出文件通常没有「第几节」和学分，页面就按「周几 + 起止时间」记，不要自己编号。
4. **剔除占位事件。** `DTSTART:19700101T000000` 一类是提醒占位，不是课。
5. **按当前日期打状态**：进行中 / 已结束 / 未开始。已结束的课保留在历史表里，不要删——它能解释某天为什么突然空了。
6. **连堂不拆。** 08:00–12:00 的课按实际起止写一条，不要拆成两节。

## 从课表推算空档

- 对每个工作日取「进行中」的时段，算 08:00–24:00 的补集，就是可自由支配的块。单独成页（如「一周时间盘」）比塞进课表页好用。
- **找出转折点**：某门课最后一次、某门课第一次，写成一句「X 月起会变松」。这是课表本身看不出来、却最影响安排的信息。
- 空档只说明物理上没人占，不说明能专注。把「按有终点的短块算，不按整天没课算」写进页面，而不是只在聊天里说。

## 页内结构

1. 来源与学期起止（一行，写清文件来源）
2. 现在还在上的（周几 / 时间 / 课程 / 地点 / 教师 / 上到哪天）
3. 已结束 / 单次调课
4. 空档（按当前在上的课算）
5. 转折点（哪几周之后会变松）
6. 日历里没有的：考试周、毕设节点、周末是否有课

## 陷阱

- 教室和教师常挤在 `LOCATION` 一个字段里（如「A101 实验室 示例教师」）：最后一个 token 是教师，其余是教室；拆错会把老师名当房间。
- 学期最后一天不等于放假：1 月初仍可能有课，别按「12 月底结束」写。
- 空档按「现在在上的课」算，不要按整学期合并算——两者差很多，用户要的是眼下。
